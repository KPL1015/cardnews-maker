# Cardnews Maker

사진, 제목, 본문을 넣어 여러 장의 1080×1080 카드뉴스를 만들고 PNG로 저장하는 간단한 웹앱입니다. 외부 라이브러리나 서버가 필요하지 않습니다.

## 파일 구조

```
cardnews-maker/
├── index.html   # 앱 화면
├── style.css    # 디자인
├── script.js    # 미리보기 및 PNG 저장 기능
└── README.md
```

## 실행 방법

1. `cardnews-maker` 폴더를 엽니다.
2. `index.html` 파일을 더블 클릭하여 Chrome, Edge 등의 브라우저로 엽니다.
3. 왼쪽의 **새 카드 추가** 버튼으로 카드뉴스 페이지를 필요한 만큼 만듭니다.
4. 카드 목록에서 편집할 카드를 선택한 뒤, 배경 이미지·제목·본문을 입력합니다. 설정은 카드별로 독립적입니다.
5. 얼굴이나 주요 피사체가 가려지면 **텍스트 위치**의 상하·좌우 슬라이더로 제목과 본문 위치를 각각 조절합니다. 직사각형 사진은 **사진 좌우·상하** 슬라이더로 보이는 영역을 조절합니다.
6. **현재 카드 PNG 저장**은 한 장만 저장합니다. **전체 카드 PNG 저장**은 모든 카드를 `cardnews-png.zip` 한 파일에 PNG로 담아 저장합니다.

로컬 서버나 패키지 설치 없이 바로 실행됩니다.
